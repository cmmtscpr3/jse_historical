Key finding The 2018 seat-level residuals are sufficiently stable to serve as informative priors for predicting 2022: using them reduces prediction error from 10.1 pp (composition-only) to 5.9 pp — a 4.2 pp improvement. Only 6 of 56 seats flipped residual sign between 2018 and 2022. The model is most vulnerable in seats where PN emerged as a dominant force after 2018 (ENDAU, BUKIT PASIR) or where exceptional local candidate effects occurred (YONG PENG).

1. Model architecture

Stage 1 — Within-group turnout decomposition

Overall seat turnout is modelled as the composition-weighted average of racial-group turnout rates. An OLS regression without intercept recovers the implied group-level rates TM, TC, TI.

Equation 1 — Turnout decomposition (OLS, no intercept; fit per election year) Ts = TM × Malay%s + TC × Chinese%s + TI × Indian%s + εs

Stage 2 — Effective voter composition

The fraction of actual voters from each racial group differs from the registered fraction whenever turnout rates diverge across groups.

Equation 2 — Effective composition (per-seat, using Stage 1 estimates) g_eff%s = ( g_registered%s × Tg ) / Ts

Stage 3 — BN support OLS (2-variable, no intercept)

BN vote share is regressed on effective Malay and Chinese composition only. Indian voters are excluded from the regression so that their contribution is absorbed into the seat-level residual alongside candidate and community effects. The no-intercept specification is consistent with the identity that BN vote share is a composition-weighted sum of within-group support rates.

Equation 3 — BN support regression (2-variable, no intercept) BN%s = BM × Malay_eff%s + BC × Chinese_eff%s + εs

Interpretation BM = implied Malay within-group BN support rate (%) — reliably estimated
BC = implied Chinese + Indian combined BN support (%) — upward-biased by omitted Indian

Stage 4 — Forward prediction (first-principles engine)

Equation 4 — Seat-level BN vote share prediction BN_preds = (BM + ΔMalay) × Malay_eff_next%s + (BC + ΔChinese) × Chinese_eff_next%s + residuals

Turnout formula — seat-specific, derived from statewide T_target and gap_MC TC,s = T_target − (avg_Malay% × gap_MC)    TM,s = TC,s + gap_MC
Ts = Malay%s × TM + (1 − Malay%s) × TC [seat-specific]

2. Reproducible regression code (Python)

The following code reproduces all estimates in this document. Requires: pandas, numpy, statsmodels.

import pandas as pd, numpy as np
import statsmodels.api as sm

BASE = "path/to/harmonised_csv_files/"
MINOR_COLS = ["PBM VOTE", "PEJUANG VOTE", "MUDA VOTE", "WARSIAN VOTE",
              "PSM VOTE", "PUTRA VOTE", "INDEPENDENT 1 VOTE",
              "INDEPENDENT 2 VOTE", "INDEPENDENT 3 CANDIDATE VOTE"]

def load_year(results_file, composition_file):
    r = pd.read_csv(BASE + results_file, encoding="utf-8-sig")
    c = pd.read_csv(BASE + composition_file, encoding="utf-8-sig")
    for df in (r, c):
        df["STATE CONSTITUENCY NAME"] = df["STATE CONSTITUENCY NAME"].str.strip()

    # Compute BN vote share and overall turnout
    for col in ["BN VOTE", "TOTAL VALID VOTES"] + MINOR_COLS:
        if col in r.columns:
            r[col] = pd.to_numeric(r[col], errors="coerce").fillna(0)
    tc = next(col for col in r.columns if "TURNOUT" in col.upper())
    r["turnout"] = pd.to_numeric(r[tc], errors="coerce")
    bn_col = next(col for col in r.columns
                  if col.upper().startswith("BN") and "VOTE" in col.upper()
                  and "CANDIDATE" not in col.upper() and "LOST" not in col.upper())
    r["bn_pct"] = r[bn_col] / r["TOTAL VALID VOTES"].replace(0, 1) * 100

    # Handle column name variation (INDIANS vs INDIAN)
    for col in ["MALAY (%)", "CHINESE (%)", "INDIANS (%)", "INDIAN (%)"]:
        if col in c.columns:
            c[col] = pd.to_numeric(c[col], errors="coerce").fillna(0)
    if "INDIANS (%)" not in c.columns and "INDIAN (%)" in c.columns:
        c["INDIANS (%)"] = c["INDIAN (%)"]

    df = r[["STATE CONSTITUENCY NAME", "bn_pct", "turnout"]].merge(
         c[["STATE CONSTITUENCY NAME", "MALAY (%)", "CHINESE (%)", "INDIANS (%)"]],
         on="STATE CONSTITUENCY NAME")
    df.columns = ["seat", "bn", "turnout", "malay", "chinese", "indian"]
    return df.dropna(subset=["bn", "turnout"]).set_index("seat")


def fit_model(d):
    # Stage 1: Turnout decomposition (Eq. 1)
    tm = sm.OLS(d["turnout"].values,
                d[["malay", "chinese", "indian"]].values / 100).fit()
    TM, TC, TI = tm.params

    # Stage 2: Effective composition (Eq. 2)
    T = d["turnout"] / 100
    d = d.copy()
    d["eff_m"] = (d["malay"]   / 100 * TM / 100) / T
    d["eff_c"] = (d["chinese"] / 100 * TC / 100) / T

    # Stage 3: 2-variable BN support OLS (Eq. 3)
    X2 = np.column_stack([d["eff_m"], d["eff_c"]])
    m  = sm.OLS(d["bn"].values, X2).fit()   # no intercept
    BM, BC = m.params

    d["residual"] = d["bn"] - m.fittedvalues
    return {"data": d, "BM": BM, "BC": BC,
            "TM": TM, "TC": TC, "TI": TI,
            "RMSE": np.sqrt(np.mean(m.resid**2)),
            "conf_int": m.conf_int(), "pvalues": m.pvalues}


# ── Run for 2018 and 2022 ──────────────────────────────────────────────────
d18 = load_year("JOHOR_2018_DUN_RESULTS_HARMONISED.csv",
                "JOHOR_2018_DUN_COMPOSITION_HARMONISED.csv")
d22 = load_year("JOHOR_2022_ELECTION_RESULTS_HARMONISED.csv",
                "JOHOR_2022_DUN_COMPOSITION_HARMONISED.csv")

r18 = fit_model(d18)
r22 = fit_model(d22)

# ── Residual stability ────────────────────────────────────────────────────
seats = [s for s in d22.index if s in d18.index]   # 56 matched seats
resid_corr  = r18["data"].loc[seats, "residual"].corr(
              r22["data"].loc[seats, "residual"])
mean_drift  = (r18["data"].loc[seats, "residual"]
             - r22["data"].loc[seats, "residual"]).abs().mean()
sign_flips  = (np.sign(r18["data"].loc[seats, "residual"])
            != np.sign(r22["data"].loc[seats, "residual"])).sum()

# ── Out-of-sample backtest: predict 2022 using 2018 model ────────────────
BM18, BC18 = r18["BM"], r18["BC"]

# Scenario 1: composition only (no residual priors)
err_no_resid = [d22.loc[s, "bn"]
               - (BM18 * r22["data"].loc[s, "eff_m"]
                + BC18 * r22["data"].loc[s, "eff_c"])
               for s in seats]

# Scenario 2: with 2018 seat residuals as priors
err_with_resid = [d22.loc[s, "bn"]
                 - (BM18 * r22["data"].loc[s, "eff_m"]
                  + BC18 * r22["data"].loc[s, "eff_c"]
                  + r18["data"].loc[s, "residual"])
                 for s in seats]

rmse_no   = np.sqrt(np.mean(np.array(err_no_resid)**2))
rmse_with = np.sqrt(np.mean(np.array(err_with_resid)**2))
print(f"RMSE without residuals: {rmse_no:.2f} pp")
print(f"RMSE with 2018 residuals: {rmse_with:.2f} pp")
print(f"Improvement: {rmse_no - rmse_with:.2f} pp")

Why 2022 RMSE is higher than 2018 The 2018 election was a mass-swing wave: BN lost Malay support uniformly, making racial composition the dominant driver and leaving small seat-specific residuals. In 2022, PN competed seriously for the first time, creating large and uneven seat-specific effects (ENDAU −25pp, YONG PENG +22.5pp) that racial composition cannot predict. The higher 2022 RMSE reflects genuine increased idiosyncratic variance, not model deterioration.

5. Out-of-sample prediction accuracy (2018 → 2022)

Using only 2018 information (BM=65.1%, BC=10.0%, 2018 residuals) with actual 2022 effective compositions, the model predicts each seat's 2022 BN vote share. Zero swing is assumed (ΔMalay=0, ΔChinese=0). The key comparison is Scenario 1 vs Scenario 2 — same parameters, differing only in whether 2018 residuals are used as seat priors.

Correct interpretation of the comparison Scenario 1 vs Scenario 2 is the proper apples-to-apples test: both use identical BM and BC parameters and identical 2022 effective compositions. The 4.2 pp improvement comes purely from the r=0.851 persistence of local effects — seats that structurally over- or under-performed in 2018 tend to do so in 2022 as well. The "oracle" comparison using 2022 residuals (RMSE=0) is mathematically trivial and not a meaningful benchmark.

7. Key limitations and analyst guidance

LimitationEffectMitigation
Residual drift (~4.2 pp/cycle) Genuine uncertainty on top of model RMSE Widen marginal threshold to ±11 pp; use seat overrides for volatile seats
BC upward-biased by omitted Indian ΔChinese parameter changes from ~12.8% baseline, not 0% Poll translation: ΔChinese = poll Chinese BN% − 12.8 (not − 0)
PN emergence post-2018 ENDAU, BUKIT PASIR residuals not predictable from 2018 Override these seats with local candidate intelligence
Ecological inference limits BM and BC are statewide averages, vary across seat types MRP with individual survey data would improve seat-level accuracy
Turnout formula uses statewide avg ~2-3 pp error in per-seat effective composition Acceptable given model RMSE; improved by actual per-seat turnout data
Data: Election Commission of Malaysia (SPR). 2018 and 2022 Johor DUN state election results. All names harmonised to 2022 constituency boundaries. Analysis: 2-variable joint OLS on effective voter composition (Malay + Chinese), no intercept. Indian voters absorbed into seat-level residuals alongside candidate and community effects.
